# CyberSecurityBotPart2

## Project Overview
CyberSecurityBotPart2 is a cybersecurity awareness chatbot developed using C# and WPF. The chatbot is designed to educate users about cybersecurity topics such as phishing, password safety, privacy awareness, and general online safety practices.

The application includes interactive responses, sentiment detection, memory storage, voice greeting integration, and an enhanced graphical user interface.

---

## Features
- Cybersecurity awareness tips
- Keyword response system
- Sentiment detection
- Memory storage
- Voice greeting using WAV file
- WPF graphical user interface
- Interactive chatbot responses

## Installation and Setup
1. Download or clone the repository.
2. Open `CyberSecurityBotPart2.slnx` in Visual Studio.
3. Restore packages if required.
4. Run the project using the Start button.

---

## Usage Example
1. Launch the application.
2. Interact with the chatbot.
3. Ask cybersecurity related questions.
4. Receive awareness tips and responses.
